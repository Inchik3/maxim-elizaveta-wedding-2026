# Критерии приёмки

## Визуальное соответствие

- [ ] Основная страница воспринимается как светлая дорогая свадебная открытка.
- [ ] Композиция, пропорции, декоративная плотность и порядок секций близки к главному макету.
- [ ] Кружево заметно присутствует на странице, но не перекрывает контент.
- [ ] Жемчужные нити и кластеры используются как связующий мотив.
- [ ] В hero присутствует пара оригинальных белых лебедей.
- [ ] Фото пары используется как главное фото в овальной или фигурной раме.
- [ ] Нет копирования уникальной графики или кода референсов.
- [ ] Секции дресс-кода нет ни в одной части сайта.

## Конверт

- [ ] При первом входе показывается бордовый полноэкранный конверт.
- [ ] Есть светлая карточка, кружевная рама и сургучная печать.
- [ ] Конверт открывается по клику, тапу, Enter и Space.
- [ ] Во время открытия повторная активация не ломает сцену.
- [ ] После открытия прокрутка разблокируется и фокус переходит в hero.
- [ ] Повторный показ управляется настраиваемой опцией.
- [ ] Reduced-motion заменяет сложную анимацию коротким безопасным переходом.

## Контент

- [ ] Имена `Максим & Елизавета` одинаково указаны во всех секциях.
- [ ] Дата везде указана как 29 августа 2026 года.
- [ ] Таймер ведёт отсчёт до 29.08.2026 14:35 по Москве.
- [ ] Программа содержит все четыре заданных этапа и времена.
- [ ] Указаны оба правильных адреса.
- [ ] RSVP принимается до начала свадьбы 29.08.2026 14:35.

## Музыка

- [ ] Музыка не запускается автоматически.
- [ ] Кнопка переключает play/pause и отражает состояние.
- [ ] Начальная громкость около 35%.
- [ ] При отсутствии файла интерфейс остаётся стабильным.

## Локации

- [ ] Есть отдельные блоки ЗАГСа и ресторана.
- [ ] У каждой локации видны заголовок, адрес, карта и маршрутная кнопка.
- [ ] Обе маршрутные кнопки используют предоставленные ссылки Яндекс Карт.
- [ ] При ошибке карты адрес и маршрут остаются доступными.

## RSVP

- [ ] Имя и статус обязательны.
- [ ] Комментарий необязателен.
- [ ] До выбора присутствия алкогольный опрос скрыт.
- [ ] При присутствии алкогольный опрос появляется.
- [ ] При отсутствии опрос скрывается и выбор очищается.
- [ ] Доступны все семь заданных вариантов.
- [ ] Можно выбрать несколько напитков.
- [ ] `Без алкоголя` взаимоисключается с алкогольными вариантами.
- [ ] `Свой вариант` раскрывает обязательное уточняющее поле.
- [ ] Присутствующий гость не может отправить форму без выбора напитка.
- [ ] Во время отправки повторная отправка заблокирована.
- [ ] Есть состояния успеха, ошибки и демо-режима.
- [ ] При ошибке сети введённые данные не теряются.

## Адаптивность и доступность

- [ ] Проверены 320, 375, 390, 430, 768, 1024 и 1440 px.
- [ ] Горизонтального скролла нет.
- [ ] Декор не перекрывает текст, кнопки и поля.
- [ ] Интерактивные области не меньше 44×44 px.
- [ ] Все действия доступны с клавиатуры.
- [ ] Видна фокус-обводка.
- [ ] Основной текст и контролы соответствуют WCAG AA по контрасту.
- [ ] Декоративные изображения не засоряют вывод скринридера.
- [ ] Форма имеет связанные подписи, группы и ошибки.
- [ ] `prefers-reduced-motion` соблюдается во всём сайте.

## Техническая готовность

- [ ] Редактируемые данные вынесены в `src/data/wedding.ts`.
- [ ] Аудио ожидается по пути `public/audio/wedding-song.mp3`.
- [ ] RSVP URL читается из `VITE_RSVP_SCRIPT_URL`.
- [ ] Подготовлен отдельный код Google Apps Script для записи строк в Google Sheets.
- [ ] Скрипт записывает ответы в таблицу `1zinyyqXwi3Ts1-KRHa1xA7NzDvqlHjTzbDmDi9YNBhA`, лист `gid=0`.
- [ ] При пустом URL доступен демо-режим.
- [ ] Блок согласия на обработку данных отсутствует.
- [ ] Проект успешно выполняет `npm install`, `npm run dev` и `npm run build`.
- [ ] В консоли нет необработанных ошибок при основных сценариях.

## Финальная визуальная сверка

Приёмка проводится не только по наличию элементов. Финальный результат должен одновременно отвечать трём условиям:

1. основной сайт композиционно близок к светлому утверждённому макету;
2. вступление узнаваемо связано с бордовым кружевным конвертом из референсов;
3. фото реальной пары выглядит центральной частью дизайна, а не вставленным поверх шаблона изображением.
