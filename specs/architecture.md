# Архитектурная спецификация

## Технологический контур

- Vite.
- React.
- TypeScript в строгом режиме.
- CSS Modules либо обычные локально организованные CSS-файлы.
- Framer Motion допустим для конверта и появления секций, если итоговый вес оправдан.
- Без Bootstrap и тяжёлой UI-библиотеки.

## Конфигурация данных

`src/data/wedding.ts` должен быть единственным основным источником редактируемого контента:

- имена пары;
- дата, время и часовой пояс;
- тексты;
- программа дня;
- две локации и маршрутные ссылки;
- настройки вступительного конверта;
- подпись и путь музыки;
- варианты алкоголя;
- срок RSVP.

Подтверждённые значения: `Максим & Елизавета`; срок RSVP — до начала свадьбы `29.08.2026 14:35`.

Компоненты не должны дублировать эти значения строковыми литералами.

## Состояния приложения

### Конверт

- `closed` — исходное состояние.
- `opening` — выполняется анимация, повторный клик игнорируется.
- `opened` — hero доступен, overlay уходит.
- Настройка `showIntroOncePerSession` определяет работу с `sessionStorage`.

### Музыка

- `idle` — файл ещё не воспроизводился.
- `playing`.
- `paused`.
- `unavailable` — файл отсутствует или не поддерживается.

Один экземпляр `audio` живёт на уровне приложения, чтобы не пересоздаваться при прокрутке.

### RSVP

- статус участия: пусто / присутствует / отсутствует;
- выбранные напитки: множество значений;
- собственный вариант: строка;
- отправка: idle / submitting / success / error / demo-success.

При смене статуса на отсутствие выбор алкоголя очищается.

## Отправка RSVP

Сервис `rsvpApi.ts`:

- получает нормализованный объект формы;
- добавляет дату отправки;
- при наличии URL выполняет POST;
- при отсутствии URL возвращает контролируемый демо-результат;
- преобразует ошибки сети в понятный результат для интерфейса;
- не логирует персональные данные в production.

Формат тела и требования CORS необходимо согласовать с финальным Google Apps Script. Предпочтителен простой JSON-контракт с явными полями и ответом `{ success: true }`.

В будущей реализации также подготавливается отдельный Google Apps Script, который создаёт строку в таблице с согласованными колонками и возвращает клиенту результат операции. После его ручного развёртывания полученный URL помещается в `VITE_RSVP_SCRIPT_URL`.

Параметры скрипта:

- Spreadsheet ID: `1zinyyqXwi3Ts1-KRHa1xA7NzDvqlHjTzbDmDi9YNBhA`;
- целевой лист: лист с `gid=0`;
- скрипт открывает таблицу по ID, а не полагается на активную таблицу;
- при первом запуске проверяет заголовки колонок;
- обрабатывает POST-запрос формы и добавляет одну строку атомарно;
- использует блокировку на время записи, чтобы одновременные ответы не конфликтовали;
- возвращает JSON с признаком успеха или безопасным сообщением об ошибке;
- развёртывается как веб-приложение, доступное отправителю формы.

## Карты

- Карточка локации получает данные из конфигурации.
- iframe считается декоративным удобством, а не критической функцией.
- Маршрут открывается обычной ссылкой в новой вкладке с безопасными атрибутами.
- Перед реализацией ссылки и геоточки проверяются вручную.

## Ассеты

- Фото пары подготавливается в оптимизированных форматах, оригинал сохраняется вне публичного бандла.
- Декор — локальные SVG, создаваемые специально для проекта.
- Бумажная фактура — небольшой WebP с возможностью бесшовного повторения.
- Аудио не добавляется без предоставленного пользователем файла.
- У каждого ассета фиксируется назначение и безопасная зона кадрирования.

## Доступность

- Intro реализуется как доступный modal-like overlay с одной главной кнопкой.
- После открытия фокус переводится на начало hero.
- Музыкальная кнопка сообщает `Включить музыку` / `Поставить музыку на паузу`.
- Группы статуса и алкоголя используют `fieldset` и `legend`.
- Сообщения формы объявляются через корректную live-region.
- Скрытие блока алкоголя удаляет его из фокусного порядка.

## Обработка ошибок

- Отсутствие аудио не нарушает загрузку страницы.
- Ошибка карты не скрывает адрес.
- Недоступный `sessionStorage` не блокирует вступление.
- Ошибка сети сохраняет введённые данные и предлагает повторить.
- Неудачная загрузка декоративного ассета не мешает чтению контента.
