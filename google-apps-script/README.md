# Подключение Google Apps Script

1. Откройте таблицу RSVP.
2. Выберите «Расширения» → «Apps Script».
3. Замените содержимое файла `Code.gs` кодом из этого каталога.
4. В настройках проекта установите часовой пояс `Europe/Moscow`.
5. Нажмите «Развернуть» → «Новое развертывание».
6. Выберите тип «Веб-приложение».
7. Выполнять от имени: вы.
8. У кого есть доступ: все.
9. Скопируйте URL веб-приложения и укажите его в `VITE_RSVP_SCRIPT_URL`.

Скрипт сам создаст заголовки в первой строке листа `gid=0` и будет добавлять по одной строке на каждый ответ.
